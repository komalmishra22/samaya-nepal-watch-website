# Samaya Nepal Watch Website

This is a first-year website development coursework project created for a watch brand named Samaya Nepal. The website includes multiple pages for products, blogs, research, team information, and CV pages.

## Features

- Home page
- Product page
- Blog page
- Research page
- Team page
- CV pages
- Navigation bar
- Image-based product sections
- Basic JavaScript functionality
- Responsive website structure

## Technologies Used

- HTML
- CSS
- JavaScript

## Project Structure

- `Index.html` - Main homepage
- `HTML/Blog.html` - Blog page
- `HTML/Product.html` - Product page
- `HTML/Research.html` - Research page
- `HTML/Team.html` - Team page
- `CSS/Style.css` - Main stylesheet
- `JavaScript/Script.JS` - JavaScript file
- `Watch Element/` - Images and website assets

## Learning Outcome

This project helped me understand website structure, page linking, navigation design, CSS styling, image handling, JavaScript basics, and multi-page website development.
